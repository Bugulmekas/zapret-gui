# ROADMAP.md

Планы развития Zapret Control. Версия не меняется — отметки только о состоянии работ.

## Выполнено

- **UI-редизайн** (ветка `feature/ui-redesign`, коммит `e408190`): левый сайдбар 216 px с пятью разделами (Обзор / Настройки / Инструменты / Тесты / Обновление) + «О программе» и версия внизу; раздел «Обзор» — hero-карточка (режим zapret, Запустить/Остановить, стратегия службы / IPSet / WinDivert) + список стратегий + карточка «Служба Windows»; журнал — нижняя раскрывающаяся панель; темы (Светлая / Тёмная / Неон) в «Настройки» → «Оформление»; окно 1200×820 (min 1000×640, при старте подгоняется под рабочую область −40 px, не меньше 940×620).

## Остальное (бэклог, без приоритета и сроков)

1. **Производительность UI-потока** — главный таймер 2 с (`Update-AllStatus` + `Read-WinwsLog`) работает в потоке интерфейса; тяжёлые проверки не должны блокировать окно.
2. **Безопасность самообновления** — замена скриптов при обновлении GUI (`Install-GuiUpdateAction`) проверяет синтаксис и версию, но не подлинность архива (SHA256/подпись); см. `tools\Test-ZipSlip.ps1`.
3. **Тесты/CI** — в `ci.yml` пока только синтаксис, BOM, набор файлов, сверка версии и XAML; прогоны `tools\` (Test-Xaml, Test-UiSmoke, Capture-UiPreview, Test-Contrast, Test-ZipSlip) в CI ещё не подключены.
4. **Атомарная запись конфига** — `Save-Config` пишет `data\config.json` напрямую (`WriteAllText`); требуется запись во временный файл с последующим переименованием.
